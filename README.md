# CompassLK Travel Planner

CompassLK Travel Planner is a modern, responsive web application designed to help travelers discover destinations, explore locations, and organize their travel plans in a simple and user-friendly way. The platform combines interactive maps, destination information, and travel planning features to provide a convenient digital travel experience.

Key Features

🌍 Destination Exploration – Discover and explore travel destinations.

🗺️ Interactive Maps – View and interact with locations using Mapbox GL.

📋 Travel Planning – Organize and manage travel plans efficiently.

🔐 User Authentication – Secure user authentication powered by Supabase.

💾 Data Management – Store and manage application data using Supabase.


📱 Responsive Design – Optimized for desktop, tablet, and mobile devices.
🎨 Modern UI – Clean and responsive interface built with Tailwind CSS and shadcn/ui.


Technology Stack


Frontend: React.js, TypeScript, Vite

Styling: Tailwind CSS, shadcn/ui, Radix UI

Backend & Database: Supabase

State & Data Fetching: TanStack React Query

Routing: React Router

Maps: Mapbox GL

Forms & Validation: React Hook Form, Zod

Charts: Recharts

Icons: Lucide React

Project Purpose


The main goal of CompassLK is to provide travelers with a centralized platform for discovering destinations and planning trips while demonstrating the practical use of modern frontend technologies, cloud-based services, interactive maps, and responsive UI development.
